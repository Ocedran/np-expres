API / CRUD

O que foi implementado?

Rotas REST com JSON
Banco SQLite conectado à API
Operações de criar, consultar, atualizar e excluir
Tratamento de registros inexistentes e erros

Como funciona?

O cliente ou a interface envia uma requisição para a API.

A API acessa o banco, executa a operação e devolve uma resposta.

Fluxo: requisição → rota → banco → resposta
